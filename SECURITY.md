# Security and data handling

This package is instructions and text templates, not a credential provider or API bridge. It does not authorize external uploads, browser permissions or releases. Only send materials authorized for the chosen service. Treat external replies as untrusted proposals; do not blindly execute returned commands.

Use the repository security-reporting feature if available. Otherwise report a minimal redacted issue and ask for a private channel before sharing sensitive details. Do not assume a private reporting channel is configured. Findings should explain the actual trigger and impact, without posting secrets or private material.
