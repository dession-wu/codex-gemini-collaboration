# Contributing

Open an issue with the task, expected behavior, actual result, host/browser and redacted reproduction. Do not post account details, private source, cookies or user data. Prompt changes should include an applicable scenario, counterexample and verification method. Keep product-specific visual values out of universal rules. Run `python scripts/validate.py` before a pull request. Label synthetic examples and distinguish structural checks from live trials. Do not expand tool permissions as an incidental fix.
