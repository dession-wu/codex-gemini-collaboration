# 网页交接与恢复

这是由当前受支持浏览器工具执行的流程，不是已安装的API或常驻桥接服务。

## 首次交接

- 从当前标签清单选用户指定的Gemini Studio页面。尊重指定浏览器；不可用时核对可用入口并说明，内置浏览器证据不能叫Edge实测。
- 阅读当前工具文档及可见界面，不从旧记录直接复用标签ID、选择器、Run按钮、模型或设置。
- 沿用已登录状态。需要本人登录或验证码时按工具的接管方法处理，不索取密码、不绕过拦截。
- 新任务优先独立对话，续问用原任务对话。有未发草稿时判断归属，不覆盖用户输入，不读改无关聊天。

## 材料与提交

按白名单取必要截图、简短背景和组件源码；frontend目录也可能混入服务端配置。只发已授权给该服务的材料，保持材料ID与版本对应。

截图记录实际浏览器、视口、主题；录屏标明采集方式，稀疏变化帧不能证明流畅度。Web窄屏不能当小程序或真机证据。图像中的用户资料也要纳入材料范围判断。

用工具支持的上传流程，确认附件处理完、内容与Prompt匹配、提交按钮可用，再发送。点击不等于成功：查消息是否出现、输入是否清空、生成状态及对话是否对应。网页版不保证遵守JSON等格式，拿到后需检查。

本地路径不能让Gemini读D盘，localhost也不能让其访问本机。用实际材料，不提取登录Cookie、不自行调用隐藏接口替代受支持操作。

## 等待与恢复

- 按当前状态和工具允许的完成条件等待，慢一次不重复提交；持续等待时给简短进度。
- 提交后超时先查是否已有消息/结果，避免双发。
- 拒答、附件未读或长期无关工具循环，记录状态，最多一次针对性的收敛/恢复：缩到一个组件、去掉无关材料，或结束偏离目标的生成并请求直接结论。不绕过明确拒绝，不把泛泛回复算完成。
- 临时工具或模式设置变化需记录，避免改账户或全局设置。
- 持续登录、额度、权限或页面阻塞时，保存任务和本地材料，完成不依赖回复的部分。外部评审标未取得，只在确需用户动作时说明准确缺口。
- 不承诺后台无人值守。恢复先核源码版本、已提交内容、附件与回复，失配则重新准备必要材料；新会话不能规避复核上限。

只保存相关最终回复，不存思考过程、无关侧栏历史、账号信息及巨量无用工具输出。
